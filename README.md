# MeshMind

一个本地优先的桌面笔记应用：Tauri 2 + React 19 + SQLite。
笔记、附件、全文索引与向量索引全部存在本机，**默认不联网**。

## 功能

- 富文本编辑（TipTap），改完自动保存
- 全文检索：中文字面、全拼连写（`zhishitupu`）、拼音首字母（`zstp`）三条通道
- 快速捕捉窗口：全局热键随手记一条（macOS `Opt+Space`，Windows `Ctrl+Alt+Space`）
- 标签（正文里写 `#标签` 即可）、回收站、截图粘贴与附件去重
- 应用内更新
- **AI 与知识问答**（默认关闭，见下）

常用快捷键：`⌘K` / `Ctrl+K` 搜索，`⌘L` / `Ctrl+L` 开合右侧问答栏。

## 开发

```bash
pnpm install
pnpm tauri dev          # 起应用
pnpm test               # 前端单元测试（vitest）
pnpm e2e                # 界面交互测试（Playwright + 假 IPC）
cargo test --workspace  # Rust 测试
pnpm tauri build        # 打包
```

真机验收清单在 `docs/manual-verification.md`——自动化测试结构上够不着的部分
（真实模型服务、全局热键、托盘、安装包）都在那里。

## 启用 AI

**AI 默认是关闭的。** 不开的话应用不会发出任何一个出站请求，行为和没有这个功能时完全一致。

### 支持哪两类服务

MeshMind 不自带模型，也不代理任何服务，需要你自己提供一个：

- **OpenAI 兼容的服务**：OpenAI 本身、DeepSeek、以及任何遵循同一套协议的网关。
  Base URL 要带 `/v1`，例如 `https://api.deepseek.com/v1`，并且需要 API Key。
- **Ollama**：跑在本机上的模型。Base URL 是裸的端口，例如 `http://localhost:11434`，
  不需要密钥。选这条的话，笔记内容不会离开这台机器。

两类都要各配一个**对话模型**和一个 **Embedding 模型**。

### 在哪里填

「设置 → AI 与知识问答」。填完可以点「测试连接」——它会真的各发一次 embedding 与对话请求，
embedding 和对话分两行报结果（模型名写错时常常是「embedding 通了、对话不通」这种半通状态）。

配好之后再打开总开关。打开时会先告诉你**要为多少篇笔记建索引**，
确认之后才真正开始——在你点「继续」之前，一个模型请求都不会发出去。
索引在后台跑，可以关掉设置面板。

### 密钥存在哪里

**API Key 以明文存在本机的 SQLite 数据库里**（`meshmind.db`，和你的笔记同一个文件）。
没有引入系统钥匙串。这意味着：

- **拷贝、同步或分享这个文件的人，同时拿到了你的可计费凭证。**
  备份到 iCloud / OneDrive / Dropbox 之前请知悉这一点。
- 密钥只有一条单向的写入路径，**永远不会经 IPC 回到前端**，
  所以它不会出现在前端日志、错误上报或者你的截图里。
- 想删掉的话，设置面板里有「清除密钥」。切换到 Ollama 之后旧密钥也不会自动消失，
  界面会继续显示「已设置」并保留清除入口。

数据库文件的位置：

- macOS：`~/Library/Application Support/com.meshmind.desktop/meshmind.db`
- Windows：`%APPDATA%\com.meshmind.desktop\meshmind.db`

### 提问时有什么东西离开本机

启用之后：

- **建索引时**：每篇笔记会被切块，发给你配置的 **Embedding 服务**换成向量。
- **提问时**：先把问题发给 Embedding 服务，检索出最相关的几个**笔记片段**，
  再把这些片段连同你的问题一起发给你配置的**对话服务**。

也就是说，**离开本机的是被检索命中的那几个片段，不是整个笔记库**——但那些片段是原文。
回答里的 `[1]` `[2]` 对应用到的片段，点一下就跳到那篇笔记。

关掉总开关会立刻停掉后台索引线程、取消在飞的提问，并把内存里的向量索引还给系统；
之后不再有任何出站请求。
